# nexdy-skyper

SkyperStyle adalah kumpulan library **CSS dan JavaScript** dirancang untuk mempermudah proses codingan menjadi effisien bagi para pengembangan web lebih modern dan interaktif. Dengan penulisan code yang singkat, modern, dan effisien, nexdy-skyper membantu developer menciptakan tampilan website yang efisien, elegan, dan mudah digunakan. Proyek ini dibuat untuk belajar sekaligus berbagi gaya desain yang unik dan ringan.

## Library
``` 
<link rel="stylesheet" href="https://skyperstyle.netlify.app/skyperstyle.css">
```
jika mengalami kesulitan untuk menggunakan. sebagai contoh penggunaan library pada html 
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <link rel="stylesheet" href="https://skyperstyle.netlify.app/skyperstyle.css">
</head>
<body>
    
</body>
</html>
```
